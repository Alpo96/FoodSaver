Egy éltelmentő programot készítettem, főleg az adatbázis és a C# gyakorlása érdekében.
Az alapja egy MSSQL adatbázis.
"LINQ To SQL" adatbázis leképezővel készítettem. Ma már egy modernebb "Entity Framework core" adatbázis leképezőt használtok.

Igyekeztem a legtöbb adatbázis műveletet lefedeni benne:
- Lekérdezések (Query/Method syntax)-al.
- Beszúrások
- Törlések
- Módosítások
